# Selam, Ben Yiğit Emre Odabaş  

Web teknolojileri, veritabanı mimarileri ve full-stack geliştirme süreçleriyle ilgilenen bir yazılım geliştiriciyim. Projelerimde modern arayüzler tasarlamayı, arka planda ise Supabase gibi araçlarla hızlı, ölçeklenebilir veritabanı çözümleri kurmayı seviyorum.

---

###  Nelerle Uğraşıyorum?

- 🛠️ **Ön Yüz (Frontend):**  JavaScript, HTML5/CSS3 ve Tailwind CSS ile dinamik, kullanıcı dostu arayüzler geliştiriyorum.
- ⚙️ **Arka Yüz (Backend) & Veritabanı:** Node.js, Supabase kullanarak veritabanı yönetimi, kimlik doğrulama (Auth) ve API entegrasyonları yapıyorum.
- 📌 **Harita & Konum Entegrasyonları:** OpenStreetMap ve harita servisleriyle özel keşif rehberleri ve konum tabanlı uygulamalar üzerine çalışıyorum.
- 📦 **Dağıtım & Sürüm Kontrolü:** Git, GitHub, Netlify ve Vercel araçlarını aktif olarak kullanıyorum.
